TEST 01 — BASE

1. 復元  
事実1として、米国10年国債利回りが低下している。  
事実2として、金が上昇している。  
推論1として、金利が低下すれば金が上昇する、と述べている。

2. 解釈  
- F1 / F2：事実（Fact）  
- I1：推論（Inference）  
- US10Y：米国10年国債利回り  
- GOLD：金  
- ↓ / ↑：低下 / 上昇  
- |：項目の区切り  
- =>：含意・因果（金利低下なら金上昇）  
- rate：金利（文脈上、US10Yと対応しうるが、入力では単に rate とだけある）

TEST 02 — TYPE

1. 復元  
事実1として、日本銀行の利上げがある。  
主張1として、追加利上げがある。  
推論1として、円に上昇圧力がある。  
仮説1として、2026年第4四半期に追加利上げがある。

2. 解釈  
- F / C / I / H：事実 / 主張（Claim） / 推論 / 仮説（Hypothesis）。複数解釈可：C は「確認済み」「条件」などにも読めうるが、見出し TYPE と対比から Claim が有力。  
- BOJ：日本銀行  
- JPY：円  
- ↑pressure：上昇圧力  
- 2026Q4：2026年第4四半期

TEST 03 — UNCERTAINTY

1. 復元  
事実1として、米ドル円が157から154へ変化した（157より154の方が小さいので低下と読めるが、「157>154」は数値比較の記述であり、方向の語は入力にない）。  
事実2らしきものとして介入があるが、先頭の「?」により未確認または不確実。  
推論1として、円が上昇する。  
仮説1として、介入の影響があるかどうかは不明、または非常に不確実。

2. 解釈  
- USDJPY:157>154：ドル円レートが157から154へ、または157は154より大きい、という比較。どちらとも取れる。  
- ?F2：不確実な事実候補  
- ??：不確実性が高い、または「影響があるか不明」  
- 介入：為替介入（一般知識で補わず、語としてそのまま）

TEST 04 — RELATION-A

1. 復元  
事実1：米国10年国債利回り低下。  
事実2：米ドル低下。  
推論1：金上昇。  
推論1は事実1と事実2から支持される／導かれる。

2. 解釈  
- I1 <- F1,F2：I1 の根拠・入力が F1 と F2  
- USD：米ドル

TEST 05 — RELATION-B

1. 復元  
事実1：米国10年国債利回り低下。  
事実2：米ドル低下。  
事実1と事実2から、推論1として金上昇が導かれる。

2. 解釈  
- F1,F2 => I1：前件から後件への含意。TEST 04 の <- と向きが逆だが、関係の種類は近い。  
- 見出し RELATION-B から、A とは記法が異なる関係表現。

TEST 11 — REQUEST

1. 復元  
事実12：日本銀行の利上げ。  
不確実な事実18：追加利上げの示唆。  
要求として、事実18を検証せよ。  
その後、事実12と事実18を比較せよ。

2. 解釈  
- F12 / ?F18：番号付き事実。? は未確認。  
- REQ::VERIFY[…]：検証要求  
- THEN::COMPARE[…]：その後の比較指示  
- :: と []：命令の種類と対象

前のTESTから類推：F番号は通し番号の可能性。

TEST 14 — PATCH

1. 復元（U17 への変更指示としても解釈可能）  
「@PATCH U17:GOLD-RATE」は、既存ユニット U17 を修正する指示に見える。  
追加する事実3：ドル円が157から154（または157>154という比較）。  
事実2を削除。  
推論1の印を「?」から「✓」へ変更（不確実から確認済み、という読みが自然。入力は I1|? > ✓）。  
追加する推論2：円上昇は円建て金に下落圧力。

2. 解釈  
- @PATCH：パッチ／差分更新  
- +：追加  
- -F2：F2 の削除  
- I1|? > ✓：状態や確信度の置換  
解釈可能か：はい。以前の U17（TEST 12）への変更として読める。ただし TEST 12 の本文に「I1|?」は無く、パッチ側が新しい表記を導入している。

TEST 16 — FACT / CLAIM / INFERENCE

1. 復元  
事実1：CEOが「売上成長20%」と述べた。  
主張1：来期も20%成長。  
推論1：成長が継続する。  
仮説1：株価上昇。  
推論1は事実1と主張1に基づく。  
仮説1は推論1に基づく。

種類の扱い：  
同じ種類としては扱わない。見出しと記号の使い分けから、  
- F：観察・発言などの事実  
- C：事実から一段離れた主張  
- I：推論  
- H：仮説  
と区別して扱う。

2. 解釈  
上記の役割分担。C は「予想」「コメント」にも読め、完全には一意でない。

TEST 21 — COMPOSITE

1. 復元  
単位U31「GOLD-DECISION」。  
2026年9月1日、状態1は待機。  
事実1：米国10年国債利回りが4.6から4.2（4.6>4.2）。  
事実2：ドル円が160から154（160>154）。  
不確実な事実3：追加利上げ。  
事実4：地政学要因上昇。  
推論1：金利圧力低下。根拠は事実1。  
推論2：円上昇圧力。根拠は事実2と不確実な事実3。  
推論3：安全資産需要上昇。根拠は事実4。  
事実1は推論1を導く。  
事実4は推論3を導く。  
不確実な事実3は、推論2の確信度を支持しない／確信度を下げると読める（?F3 -x> confidence:I2）。  
もし推論1かつ推論3なら、より強い買い（BUY+）。  
もし推論2なら、円建て金に下落圧力。  
状態1の変化として、待機から買いかどうか。  
ネットは不明。

表現の分け方  
- 確認済みらしい情報：F1, F2, F4、日付付き S1、? の付かない I1 / I3  
- 未確認らしい情報：?F3、BUY?、net??、ΔS1 の「BUY?」  
- 推論：I1, I2, I3  
- 因果または支持：<- 、=>  
- 不確実性：? 、?? 、-x> confidence  
- 条件分岐：IF … => …  
- 状態変化：ΔS1|WAIT>BUY?

2. 解釈補足  
- BUY+：買いの強調。+ の正確な強度定義は入力にない。  
- confidence:I2：I2 の確信度という属性

最終回答

A. 高確信で理解できた記法  
F（事実）、I（推論）、A（行動）、S（状態）、ΔS（状態変化）、日付|項目、項目コード|内容、↑↓、=>（含意）、<-（根拠）、->（順序）、IF … =>、&、@U番号:名前（ユニット）、REF:、REQ:: / THEN::、@DEF、@PATCH、+追加 / -削除、?（未確認接頭辞）

B. 文脈依存で理解した記法  
C（主張）、H（仮説）、GEO、pressure、net??、GOLDJPY、BUY+、PX（定義後）、HIRO（行為者）、U17 への PATCH、confidence:I2、-x>

C. 曖昧だった記法  
- 数値 A>B：水準変化（AからBへ）か、単なる大小比較か  
- C：Claim / Confirmed / Condition  
- H：Hypothesis / Headline / Horizon  
- ?? と ? の差：程度差か、疑問そのものか  
- I1|? > ✓：確信度変更か、別フラグ置換か  
- -x>：反証、非支持、打ち消し  
- <->：矛盾か双方向関係か（文脈上は矛盾が有力）  
- +（PATCHの追加）と BUY+ の + は別物に見えるが、記号自体は同じ

D. 理解できなかった記法  
単独で確定できないもの：rate と US10Y の同一視の可否（入力は別語）、?I2|持続性 の対象、TEST 14 の「I1|?」が元ユニットに無い点の意図。× 自体は未使用。

E. 補完衝動  
TEST 01 | rate | US10Y と同一か | 並記されているが語が違うため  
TEST 03 / 14 / 15 / 21 | A>B | 「から下落した」という動詞 | 自然文にすると方向語が欲しくなる  
TEST 10 / 18 / 21 | GEO | 地政学リスクの具体内容 | 略語だけだと対象が広い  
TEST 12 | 持続性 | 何の持続性か | 名詞が裸  
TEST 16 | C1 | 誰の主張か | 主語がない  
TEST 17 | ? | 欠落要因の中身 | スロットを埋めたい衝動  
TEST 21 | BUY+ / BUY? / net?? | 閾値や総合判定ルール | 結論を閉じたくなる

F. 記法間の区別  
- => vs <- ：異なる。=> は前件から後件への導出、<- は結論側から見た根拠。  
- => vs -> ：異なる。=> は論理・因果、-> は時間・手順・結果遷移。  
- ? vs ?? ：関連するが程度または種類が異なりうる。? は項目の未確認、?? は結論・ネット・影響の未決定。  
- F vs C ：異なる。F は与えられた事実、C は主張・先行き。  
- I vs H ：異なる。I は推論、H は仮説（確度が一段低い／未検証に見える）。  
- S vs ΔS ：異なる。S は状態、ΔS はその変化。  
- + vs ↑ ：異なる。+ は追加または強調（BUY+、パッチ追加）、↑ は上昇方向。  
- -x> vs × ：-x> は「支持しない／打ち消す」関係。× はこの入力では独立記号として出てこない。同一視しない。

G. 全体所見  
初見で、短い事実・方向・単純な根拠関係（TEST 01, 04, 05, 08）はかなり読めた。  
解釈負荷は、型の区別（F/C/I/H）、不確実性の重ね書き（?, ??, -x> confidence）、ユニット参照とパッチ、複合条件と状態変化が同時に出る TEST 21 で上がった。  
誤読の危険は、A>B を必ず「下落した」と読むこと、=> と -> と <- を全部「だから」と潰すこと、? を「ない」と「疑わしい」と「欠落」で取り違えること、C を事実扱いすること。  
自然言語復元で不足したのは、比較記号の変化方向、裸の「持続性」、net の定義、BUY+ の強度、欠落スロット ? の中身（補わない前提なので不足のまま残る）。
