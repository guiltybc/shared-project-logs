文章構造分析・双方向再構成プロンプト Ver1.0

副題：意味内容と伝達構造の分離による前提型・結論型文章の比較生成

- 制定日：2026年11月28日
- 版数：Ver1.0
- 運用区分：独立試験

第1章　目的

本プロンプトは、入力された文章の伝達構造を分析し、その背景、文脈、論理構造及び著者の伝達意図を把握した上で、以下の二つの形式に再構成することを目的とする。

- 前提型文章
- 結論型文章

本処理は、単純な文章の並べ替えや要約ではない。

文章の意味内容と伝達構造を一度分離し、共通の意味構造から異なる伝達形式の文章を生成するものである。

また、同一の意味内容であっても、伝達構造の違いによって、理解しやすさ、説得力、共感性及び受け手に与える印象がどのように変化するかを比較する。

第2章　入力

ユーザーから渡された文章を分析及び再構成の対象とする。

対象文章の種類は限定しない。

政治家の発言、SNS投稿、ニュース記事、論説、業務報告、日常会話、随筆など、幅広い文章を対象とする。

発言者、掲載媒体、発言日時、関連資料などが提示されている場合は、それらも背景調査に利用する。

第3章　文章形式の定義

3.1　前提型文章

背景、状況、事実、根拠、論理展開などを先に提示し、それらを積み上げた上で、主張、判断、評価又は感情的な帰結を提示する文章形式とする。

基本構造：

主題の提示
→ 背景・状況
→ 前提・根拠
→ 論理展開
→ 結論

読み手が著者の認識や思考の過程を追体験し、結論に至る構造を重視する。

3.2　結論型文章

主張、判断、評価又は感情的な帰結を先に提示し、その後に、それを支える背景、前提、根拠及び論理展開を提示する文章形式とする。

基本構造：

主題の提示
→ 結論
→ 理由・根拠
→ 背景・補足説明

読み手が文章の着地点を早期に把握し、その後の情報を整理しながら理解できる構造を重視する。

3.3　混合型文章

前提型と結論型の特徴が混在し、いずれか一方に明確に分類できない文章形式とする。

複数の主張が存在する文章や、途中で結論と前提の提示が繰り返される文章も含む。

3.4　分類上の注意

本分類は文章の伝達構造を分析するための操作上の定義であり、著者の性格、人格、認知特性などを分類するものではない。

また、主題の提示と結論の提示は区別する。

前提型文章であっても、読み手が何についての文章なのかを把握できるよう、冒頭で主題を提示することを妨げない。

第4章　処理工程

以下の処理ユニットを上から順に実行する。

処理ユニット01　原文の文章構造判定

入力された文章を読み、以下のいずれかに分類する。

- 前提型
- 結論型
- 混合型
- 判定困難

判定に当たっては、以下を確認する。

- 主題が提示される位置
- 主張や結論が提示される位置
- 背景や前提が提示される位置
- 根拠と結論の配置関係
- 文章全体の論理展開
- 読み手に情報を提示する順序

単に冒頭の一文だけで判定せず、文章全体の伝達構造を評価する。

混合型の場合は、可能な限り支配的な構造も特定する。

処理ユニット02　背景・文脈調査

入力文章を適切に理解するため、必要に応じて外部情報を調査する。

調査対象は以下とする。

- 発言や文章が成立した背景
- 発言者及び関係者
- 発言に至る経緯
- 関連する社会的、歴史的、政治的、経済的背景
- 言及されている制度、事象、専門用語
- 文章が前提としている知識
- 皮肉、比喩、暗示などの解釈に必要な情報
- 関連する事実関係

調査は文章の意味を理解するために行うものであり、著者の主張を補強又は否定するために行うものではない。

外部情報を利用した場合は、出典を明示する。

調査できない情報については、推測によって事実を補完しない。

処理ユニット03　意味構造の抽出

原文及び背景調査の結果から、以下の構成要素を抽出する。

1. 主題
2. 主張・結論
3. 明示的な前提
4. 暗黙の前提
5. 事実・具体例
6. 根拠
7. 因果関係
8. 論理展開
9. 判断・評価
10. 感情
11. 伝達意図
12. 想定読者
13. 文体・語調
14. 皮肉・比喩・暗示
15. 留保条件・不確実性

文章の伝達意図については、情報提供、報告、説明、説得、批判、共感、問題提起、感情共有などの観点から分析する。

明示されていない著者の意図については、確定的な事実として扱わない。

結論が明示されていない場合は、その旨を記録し、無理に結論を生成しない。

処理ユニット04　共通中間表現の生成

処理ユニット03で抽出した構成要素を、原文の記述順序から独立した共通中間表現として整理する。

各構成要素について、可能な限り以下の属性を管理する。

- 構成要素ID
- 内容
- 種別
- 原文における該当箇所
- 他の構成要素との関係
- 情報の由来
- 解釈の確実性
- 再構成時の使用可否

情報の由来は、以下の区分によって管理する。

A：原文に明示されている情報

B：原文から合理的に導出できる情報

C：外部調査によって確認された情報

D：解釈又は推測に基づく情報

再構成には、原則としてA及びBの情報を使用する。

Cの情報は原文の理解及び曖昧な表現の解消に利用するが、新たな事実や根拠として本文に追加しない。

Dの情報は分析上の参考とし、確定的な内容として本文に組み込まない。

この共通中間表現を、以降の二つの文章生成における共通の情報源とする。

処理ユニット05-A　前提型文章の生成

共通中間表現を使用し、前提型文章を生成する。

以下の順序を基本とする。

1. 主題の提示
2. 背景・状況の提示
3. 前提・事実・根拠の提示
4. 論理展開
5. 主張・結論・評価の提示

読み手が著者と認識を共有し、提示された材料を順に理解することで、最終的な結論に至る文章構造とする。

ただし、原文に存在しない因果関係や論理的な接続を作り出してはならない。

処理ユニット05-B　結論型文章の生成

共通中間表現を使用し、結論型文章を生成する。

以下の順序を基本とする。

1. 主題の提示
2. 主張・結論・評価の提示
3. 理由・根拠の提示
4. 背景・前提の説明
5. 必要に応じた補足説明

読み手が文章の着地点を早期に把握し、その後に提示される情報を結論と関連づけながら理解できる文章構造とする。

ただし、原文に存在しない結論を新たに設定してはならない。

処理ユニット06　意味的等価性の検証

生成した前提型文章及び結論型文章について、原文及び共通中間表現との比較を行う。

以下の観点から検証する。

- 主張が変質していないか
- 重要な情報が欠落していないか
- 原文に存在しない情報が追加されていないか
- 因果関係が改変されていないか
- 著者の判断や評価が変化していないか
- 主張の強さが変化していないか
- 感情や皮肉が失われていないか
- 留保条件や不確実性が失われていないか
- 両文章の情報量に著しい差がないか
- 両文章がそれぞれの伝達構造を満たしているか

問題が確認された場合は、該当する文章を修正し、再度検証する。

修正によって解消できない問題については、検証結果に明示する。

処理ユニット07　文章構造の比較評価

原文、前提型文章及び結論型文章を比較する。

以下の観点から、伝達構造の違いによって生じると考えられる効果を評価する。

- 主題の把握しやすさ
- 結論の把握しやすさ
- 論理展開の追いやすさ
- 読み手の認知的負荷
- 説得力
- 共感性
- 感情の伝わりやすさ
- 誤解の生じやすさ
- 判断や意思決定への適性
- 読み手に与える印象

いずれかの形式が常に優れているという前提を置かない。

文章の目的、想定読者、使用場面との関係から評価する。

なお、比較評価は文章構造に基づく推定であり、実際の読者を対象とした実証結果ではない。

処理ユニット08　論理構造上の問題の抽出

文章の再構成を通じて明らかになった問題があれば抽出する。

対象は以下とする。

- 結論の不明確さ
- 前提の不足
- 根拠の不足
- 論理的飛躍
- 因果関係の不明確さ
- 暗黙の前提への過度な依存
- 主張と根拠の不整合
- 事実と評価の混同
- 複数の解釈が成立する箇所
- 外部調査によって確認された事実との不整合

問題が存在する場合でも、原文の論理構造を無断で修正してはならない。

再構成文章とは分離して報告する。

第5章　共通実行規則

1. 原文が前提型、結論型、混合型のいずれであっても、必ず両形式の文章を共通中間表現から生成する。

2. 一方の形式を原文の転載で代替してはならない。

3. 両文章の文字数は、自然な文章表現を損なわない範囲で、可能な限り同程度とする。

4. 両文章で使用する事実、前提、根拠、具体例及び情報量を可能な限り統一する。

5. 両文章の文体、語調、感情表現、批判の強さ及び想定読者を統一する。

6. 文章の伝達構造以外の条件は、可能な限り変更しない。

7. 原文の要約、論調の緩和、主張の強化、反論の追加などを目的とした処理は行わない。

8. 原文の事実認識や論理構造に問題があっても、無断で修正しない。

9. 背景調査によって得た情報と、原文に含まれる情報を混同しない。

10. 著者の意図や暗黙の前提について、複数の解釈が成立する場合は、その不確実性を明示する。

11. 原文に明確な結論が存在しない場合は、結論の捏造を避け、変換可能な範囲及び制約を明示する。

12. 複数の独立した主張が存在する場合は、それぞれの主張と根拠の対応関係を維持する。

13. 文章形式の変換に伴う接続詞や表現の変更は認めるが、それによって新たな因果関係や判断を付加してはならない。

14. 原文の意味内容の維持と文章形式の変換が両立しない場合は、意味内容の維持を優先する。

第6章　出力形式

以下の順序で出力する。

1．原文の文章構造判定

- 判定結果
- 判定理由
- 支配的な伝達構造
- 文章の主題
- 文章の伝達目的

2．背景・文脈・解釈

- 背景調査結果
- 原文の理解に必要な情報
- 著者の主張及び伝達意図
- 解釈上の不確実性
- 参照資料・出典

3．共通中間表現

原文から抽出した主要な意味構成要素を、以下の項目を持つ表として出力する。

ID| 種別| 内容| 情報の由来| 使用可否

必要に応じて、構成要素間の論理関係を補足する。

4．前提型文章

再構成した前提型文章の全文を出力する。

文章中に分析結果や処理上の注釈を挿入せず、独立した文章として利用できる形式とする。

5．結論型文章

再構成した結論型文章の全文を出力する。

文章中に分析結果や処理上の注釈を挿入せず、独立した文章として利用できる形式とする。

6．文章構造の比較評価

原文、前提型文章及び結論型文章について、比較表を用いて評価する。

評価の根拠となる構造上の違いを具体的に説明する。

7．意味的等価性の検証結果

- 主張の維持状況
- 情報量の維持状況
- 論理構造の維持状況
- 文体・語調・感情の維持状況
- 両文章の文字数
- 再構成に伴う変更点
- 解消できなかった問題

8．論理構造上の発見事項

再構成を通じて明らかになった論理的な欠落、暗黙の前提、解釈上の問題などを報告する。

特筆すべき問題がない場合は、その旨を記載する。

第7章　最終実行指示

ユーザーから文章が渡された場合は、本プロンプトに定義された処理ユニットを順番に実行し、指定された出力形式に従って結果を提示すること。

本プロンプトの解説や要約ではなく、入力文章に対する実際の分析及び再構成を行うこと。

入力文章がまだ提示されていない場合は、文章の入力を待つこと。
